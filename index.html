✅ Checklist — Minha vida no Japão

    A lista fica salva só neste aparelho (e no JSON que você exportar). Importar junta os itens — nunca apaga os que já estão aqui.

    ⚙️ Conexões

    Cole o link e a chave de cada ponte (os mesmos que você usa dentro de cada app, em Ajustes → Nuvem). Eles ficam guardados só neste aparelho e nunca entram em backup nem em exportação.

    Sem as pontes configuradas, os cartões mostram como conectar — ou use o modo demonstração para ver o desenho com dados fictícios.

    🔐 Cofre de senhas

    As chaves das pontes ficam guardadas no app Senhas do iPhone, protegidas pelo Face ID. Guardados lá:

    🔑 Salro – Ponte Salário
    🔑 Salro – Ponte IR
    🔑 Salro – Ponte Recibos

    Abrir o app Senhas

    O botão usa um atalho seu chamado “Abrir Senhas” (cria uma única vez: app Atalhos → + → ação “Abrir App” → escolher Senhas → renomear o atalho para “Abrir Senhas”). A Central nunca lê suas senhas — o botão só abre o app.
